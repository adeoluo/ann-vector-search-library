# ADR-0002: HNSW for approximate nearest neighbor search

- **Status:** Accepted
- **Date:** 2026-01-01

## Context
Exact nearest-neighbor search by brute force is simple but costs one distance computation per
stored vector. Tree-based methods such as k-d trees degrade toward brute force in high dimensions.
The index needs strong recall in high dimensions, incremental insertion, and a tunable
speed-recall trade-off.

## Decision
Implement Hierarchical Navigable Small World graphs. Points are inserted at a random maximum
level drawn from a geometric distribution; a greedy search descends the sparse upper layers, and a
bounded best-first search at each lower layer connects the new point to neighbors chosen by a
distance heuristic. Queries use the same descent and a width-``ef`` beam search at the base layer.

## Consequences
- Recall stays high in high dimensions, and the search width ``ef`` tunes recall against cost.
- Insertion is incremental; no global rebuild is needed to add a point.
- The graph is more complex than a flat scan, and quality depends on ``M`` and ``ef``, which the
  documentation and benchmarks make explicit.
