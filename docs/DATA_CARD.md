# Data Card - ANN Vector Search Library

## Source
- **Fully synthetic.** Vectors are generated in-process from a seeded mixture of Gaussian
  clusters. There is no external dataset, download, or network access.

## Composition
- Each vector is a point in a configurable dimension (default 16), drawn from one of several
  cluster centers with added Gaussian noise, giving real neighborhood structure.
- Queries are generated from the same kind of distribution with a different seed.

## Labels and supervision
- There are no labels. Ground truth for recall is computed by exact brute-force search.

## Provenance and licensing
- Generated by this repository's code under the MIT license. No third-party data is included.

## Filtering and contamination
- Queries use a separate seed stream from the indexed vectors, so recall is measured on points not
  identical to the queries.

## Known limitations
- The clustered synthetic distribution is favorable to nearest-neighbor search by design, so it
  demonstrates the mechanism rather than worst-case behavior.
